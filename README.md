# Accounting for Executive Decisions

財務経理の実務担当者になることではなく、財務経理人材・施策が経営に生む価値を見抜き、妥当性を検証し、採用判断へ翻訳できるようになるための8週間プログラムです。

## 8週間後の到達状態

次の6項目を、資料を見ながらではなく自力で行える状態を目指します。

1. 財務三表のつながりを、具体的な取引を使って説明できる
2. 利益が出ていても資金が不足する理由を説明・概算できる
3. 経理・管理会計・財務・内部統制・CFOの役割を区別できる
4. 候補者の経験を、売上・費用・使用資本・リスクの改善へ翻訳できる
5. ROI計算の前提漏れ、二重計上、単位間違い、過大評価を発見できる
6. 候補者紹介資料を15分でレビューし、「会う・見送る・追加確認」を判断できる

## 学習で使う共通原則

### 1. 業務ではなく存在目的から考える

「月次決算をする」「銀行と交渉する」で止めず、その結果として何を守り、何を改善する部門なのかを考えます。

### 2. 経営効果を4分類する

- 売上増加
- 費用削減
- 使用資本削減
- 損失・リスク回避

### 3. 数字は必ず構造で示す

金額だけを置かず、基準値 × 改善幅 × 単価 × 継続期間で示します。

### 4. 事実・仮定・未確認を分ける

候補者の実績、顧客の現状、一般的な仮定を混ぜません。仮定はレンジで置き、確認質問を付けます。

### 5. 分からないことを正しく特定する

専門家のように即答することより、判断に必要な不足情報を特定できることを重視します。

## 合格基準

各週の自己採点は100点満点、80点以上を合格とします。ただし、次のいずれかがあれば点数に関係なく未達です。

- 事実と仮定が混在している
- 単位または期間が混在している
- 一時効果と毎年の効果が混在している
- 同じ効果を二重計上している
- 候補者の経験と改善効果の因果関係が説明できない

最終週の評価表は [templates/final-rubric.md](templates/final-rubric.md) にあります。

## 推奨教材

最初から簿記資格の網羅学習は行いません。今回の目的に必要な順序は、経営数値の理解、資金の動き、管理会計、業務プロセス、内部統制です。

- 國貞克則『財務3表一体理解法』
- 石野雄一『ざっくり分かるファイナンス』
- 『グロービスMBAアカウンティング』
- 『グロービスMBAファイナンス』

教材を読むこと自体は成果に含めません。毎週の成果物が作成できたかで進捗を判定します。
