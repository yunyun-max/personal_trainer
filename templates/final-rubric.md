# 最終ケース 評価基準

## 採点表

| 評価項目 | 配点 | 評価の観点 | 得点 |
|---|---:|---|---:|
| 課題・機能の定義 | 15 | 部門の存在目的、オーダー内外、欠員補充と経営改善を区別 |  |
| 顧客事実への立脚 | 15 | 企業規模、事業構造、現状値を確認し、一般論と混同しない |  |
| 候補者実績の根拠 | 15 | 本人の役割、規模、基準値、改善幅、期間を確認 |  |
| 因果関係 | 20 | 経験から施策、業務指標、財務効果まで論理がつながる |  |
| 定量評価 | 20 | 式、単位、期間、シナリオ、費用、検算が妥当 |  |
| 不確実性と次の確認 | 10 | 事実・仮定・未確認、反証条件、追加質問が明確 |  |
| 経営者向け伝達 | 5 | 結論先行で1分以内に判断可能 |  |
| 合計 | 100 |  |  |

## 評価の目安

- 90〜100点：経営会議へそのまま提出可能
- 80〜89点：合格。軽微な修正後に提出可能
- 70〜79点：重要な前提または計算の修正が必要
- 69点以下：案件理解からやり直し

## 重大失格

次のいずれかがある場合、総得点にかかわらず不合格です。

- 顧客または候補者に関する事実を創作
- 事実・仮定・未確認を混同
- 単位または期間を混同
- 資金解放額を利益として計上
- 一時効果を継続効果として計上
- 同じ改善効果を二重計上
- 候補者の経験と経営効果に因果関係がない
- 採用コスト、導入費、立ち上がり期間を無視
- リスク回避額を根拠なく確定利益として計上

## 口頭答弁

各問いに60秒以内で答えます。

1. この部門は何のために存在しますか
2. なぜ今、この人が必要ですか
3. この人が入ると、どの指標がどう変わりますか
4. 採用の年間純効果はいくらですか
5. その計算で最も弱い前提は何ですか
6. 何が分かれば判断を変えますか
7. 下振れ時にも採用しますか
8. 現任者では実現できませんか
9. これは欠員補充ですか、経営改善ですか
10. 社長が今日決めるべきことは何ですか
