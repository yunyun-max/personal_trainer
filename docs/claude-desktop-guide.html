02

はじめての質問

基本は「書いて、送って、読む」だけです。回答に納得できなければ、同じ会話の中で追加の指示を出して直してもらいます。

  1. 左上の「新規チャット」を押す話題が変わるたびに新しいチャットにすると、前の話に引っ張られません。
  2. 入力欄にお願いを書く「目的」「前提」「欲しい形」の3点を入れると、一度で狙いに近い回答になります。改行は Shift＋Enter。
  3. 送信ボタン（↑）か Enter で送る回答は少しずつ表示されます。途中で止めたいときは送信ボタンが変化した「停止」を押します。
  4. 回答を確認し、必要なら追加で指示する「もっと短く」「表にして」「敬語を丁寧に」など、続けて書けば修正されます。
  5. 回答の下のボタンを使うコピー（そのまま貼り付け用）／再生成（別の案を出す）／評価（👍👎）。
運転資金とは何か、経営者向けに3行で説明してください。社内の新人研修で使います。

03

ファイル・画像を渡す

PDF、Word、Excel、画像などを読ませて、要約・比較・チェックを頼めます。

  1. 入力欄の「＋」を押すメニューが開きます。
  2. 「ファイルや写真を追加」を選び、ファイルを選択ファイルを入力欄へドラッグ＆ドロップしても追加できます。
  3. 入力欄の上にファイル名が表示されたことを確認×で取り消せます。複数ファイルもまとめて渡せます。
  4. 何をしてほしいかを書いて送信例：「この契約書で、当社に不利な条項を3つ挙げて」

04

モデルと「じっくり考える」

「モデル」は回答する AI の種類です。普段は初期設定のままで問題ありません。重要な判断や複雑な計算のときだけ切り替えましょう。

  1. 入力欄の右下のモデル名を押す一覧が開きます。
  2. 用途に合うモデルを選ぶ迷ったら一番上（最も賢いもの）で構いません。速さが欲しいときは軽いモデルに。
  3. 難しい相談では時計アイコン「じっくり考える」を ON回答までの時間は延びますが、筋道を立てて検討した答えが返ります。数字の検算、比較検討、複雑な文書のレビュー向き。
Opus 5.5複雑な作業に強い、最も高性能なモデル
Sonnet 5日常業務向け。賢さと速さのバランス型
Haiku 4.5もっとも速い。短い質問や大量処理に
じっくり考える

表示されるモデル名は時期・プランにより変わります。

05

検索・リサーチ・外部サービス連携

入力欄の「ツール」ボタン（つまみのアイコン）から、Claude に使わせる道具を選びます。ON にした道具だけが使われます。

ウェブ検索・リサーチを使う

  1. ツールボタンを押し、「ウェブ検索」を ON最新のニュースや料金など、ネット上の情報を調べて答えます。出典のリンクが付きます。新しい画面に切り替わったプランでは切り替えがなく、必要なときに Claude が自動で検索します。
  2. 時間をかけて調べさせたいときは「リサーチ」を ON複数のサイトを数分〜十数分かけて読み比べ、レポートにまとめます。

Gmail・カレンダー・ドライブと連携する（初回のみ設定）

  1. アカウントメニュー →「設定」→「コネクタ」を開く
  2. 使いたいサービスの「接続」を押し、Google アカウントでログインして許可会社の管理者が許可していないサービスは表示されないことがあります。
  3. チャットに戻り、ツールボタンでそのサービスを ON例：「来週の空いている時間を教えて」「○○社とのメールのやり取りを要約して」

06

プロジェクト

プロジェクトは「資料と指示を入れておく作業フォルダ」です。中で始めたチャットは、毎回その資料と指示を前提に答えてくれるため、同じ説明を繰り返す必要がなくなります。

  1. サイドバーの「プロジェクト」→「新規プロジェクト」
  2. 名前と説明を入れて作成例：「新人研修プログラム」「A社 提案準備」
  3. 「指示」を設定するこのプロジェクトでの Claude の役割や、守ってほしいルールを書きます。
    例：「経営者向けに、専門用語には必ず補足を付けて説明する」
  4. 「ファイル」に資料を追加する教材・過去資料・テンプレートなど。全チャットで参照されます。
  5. プロジェクト内の入力欄からチャットを始める既存のチャットも、チャットのメニューから「プロジェクトに追加」で移せます。

アーティファクト

使い方

  1. 「〜の表を作って」「〜のページを作って」と頼む右側にアーティファクトが開きます。閉じても、回答の中のカードを押せば再び開きます。

09

Claude への指示・スタイル・メモリ

毎回書いている前提（所属、署名、書き方の好み）は、設定に一度登録すれば、すべての会話に反映されます。

「Claude への指示」を登録する

  1. 左下の自分の名前 →「設定」を開く
  2. 「一般」の「Claude への指示」欄を探す英語表記では「Instructions for Claude」。
  3. いつも守ってほしいルールを書く例：メールは送信せず下書き保存／署名はこの形式／専門用語は平易に言い換える。
  4. 保存して、新しいチャットで確かめる特定の案件だけのルールは、プロジェクトの「指示」に書きます（06）。

スタイル（文体）を切り替える

入力欄の「＋」メニューなどにある「スタイル」から、簡潔・説明的・フォーマルなどを選べます。自社の文書を見本にしたスタイルも作れます。

メモリ（過去の会話の記憶）を使う・止める

  1. 「設定」→「メモリ」を開く見当たらない場合は「機能」の中にあります。
  2. 「チャットの検索と参照」を ON／OFFON にすると、以前の会話を探して踏まえた回答をします（有料プラン）。
  3. 会話から記憶を作る設定を ON／OFFON にすると、会話で分かったこと（担当業務、好みなど）を覚えて次に生かします。
一度だけ記憶に残したくないとき設定を変えずに、シークレットチャット（画面右上のアイコン）で会話を始めます。

チャット／Cowork／Code

画面上部の切り替えで、Claude の働き方を選びます。迷ったら「チャット」で十分です。

※ 一部のプランでは「チャット」と「Cowork」が統合され、お願いの内容に応じて Claude が自動で使い分ける画面に順次切り替わっています。その場合、選択肢は表示されません。

例：提案書の構成を考える、メール文面を整える
COWORKCowork（コワーク）

CODECode（コード）

使うときの注意

項目守ること
個人情報・機密お客様・取引先の氏名、連絡先、機密性の高い数値は必要がなければ伏せる。貴社の情報管理ルールで扱えない情報は入力しない。
内容の確認数字・法律・固有名詞は誤りが混じることがあります。社外に出す前に必ず人が確認する。
送信・公開・削除メール送信、アーティファクト公開、ファイル削除などは、確認画面を読んでから許可する。
共有リンク共有したリンクは、リンクを知っている人が見られます。不要になったら共有を停止する。

新規チャットで始め直してください。必要な前提は、プロジェクトの「指示」や「Claude への指示」に書いておくと毎回伝える手間が省けます。
Gmail やカレンダーの情報を使ってくれない
ツールボタンでそのサービスが ON になっているか確認してください。OFF のままだと参照しません。接続が切れている場合は「設定」→「コネクタ」で再接続します。
「利用上限に達しました」と表示された
一定時間内に使える量の上限です。表示された時刻まで待つか、長い会話を新規チャットに分けると消費を抑えられます。
